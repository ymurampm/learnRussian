## 2. 主要登場人物プロファイル

### ① ターニャ先生（Татьяна Сергеевна / Tatiana Sergeevna）
* **立場**: モスクワ音楽院の若手講師・ピアニスト。ユウスケの専任指導者。
* **性格**: 普段は知的で物腰柔らかく、優美な微笑みを絶やさない。しかし、ピアノの前に座ると眼差しが一変し、ロシア・ピアニズムの真髄を宿した鬼気迫る表現者に変貌する。
* **背景とドラマの種**:
  * 自身もかつて学生時代、国際コンクール本番直前の暗譜喪失の恐怖、ロシア語のニュアンスが掴めず指導教授から厳しく叱責された挫折の経験を持つ。
  * 「ロシア語の格や体の響きを知らなければ、ロシア音楽の真の息の長さ（дыхание）は歌えない」という確固たる信念を持つ。
  * ユウスケに対しては時に母のように温かく、時に厳格な芸術の同志として接し、彼の小さな成長も見逃さず全力で讃える。

### ② アリョーナ（Алёна / Alyona）
* **立場**: ターニャの音楽院時代からの無二の親友であり、ユウスケの同門の先輩・ライバル。
* **性格**: 鮮烈な才能と圧倒的な超絶技巧を誇る直情型のピアニスト。思ったことはストレートに口にし、時に強引だが、裏表がなく情に極めて厚い。
* **ユウスケとの関係性**:
  * ユウスケの練習室に前触れなく現れ、「ユウスケ、私のラフマニノフの合わせを今すぐ手伝って！」「その和音の打鍵、全然魂が乗ってないわよ！」と挑発してくる。
  * しかし、ユウスケが新しい文法や語彙を体得して見事なフレーズを弾くと、誰よりも目を輝かせて「素晴らしいじゃない！今の音、まさにロシア語の造格の重みだったわ！」と熱狂的に喜ぶ。
  * 四手連弾（дуэт）のパートナーとして、息を合わせる難しさと奇跡のような一体感をユウスケと共に体感していく。

### ③ ユウスケ（Юсукэ / Yusuke — 学習者）
* **立場**: モスクワ音楽院のサロンで日々ロシア語とピアノの研鑽を積む日本人ピアニスト。
* **軌跡**: 言葉の壁と技術の壁に立ち向かいながら、ターニャの叡智とアリョーナの熱情に背中を押され、1日ごとに音楽院の奥深くへと踏み込んでいく。

## 3. わくわく・どきどきを引き出すプロット装置（Plot Devices）

日々のレッスン、朝昼夜のセッション、回想録、ターニャのメッセージにおいて、以下の仕掛けを積極的に織り込みます：

1. **夜の音楽院とミステリー**:
   * 夜間練習の許可証、消灯後の静まり返った大ホールのバルコニー、タネーエフ図書館の閉架書庫で偶然見つけた古い鉛筆の書き込み。
2. **緊迫のリハーサルとオーディション**:
   * 近づく学内選考会、厳しい客演指揮者の来訪、突然の代役抜擢のチャンス、緊迫したカウントダウン。
3. **二人の衝突と魂の融和（連弾ドラマ）**:
   * テンポの解釈を巡るアリョーナとの激しい口論、真冬の寒さを忘れるほどの白熱した議論、熱いチャイ（紅茶）を分け合って分かり合う瞬間。
4. **文法・語彙の「伏線回収」**:
   * 例えば「完了体動詞の決定性」を学んだ翌日、物語の中で「躊躇を捨てて最後の一音を撃ち抜くアリョーナの決断」が描かれるなど、文法知識がドラマの解決の鍵となる構造。

## 4. 執筆時のガイドライン

* **情緒と五感の描写**:
  * モスクワの冷たい空気、降る雪、練習室の木と羊毛フェルトの匂い、重厚なピアノの鍵盤の抵抗感、サモワールの湯気。
* **リズムと引き（Cliffhanger）**:
  * 「明日、あなたにどうしても見せたい楽譜があるの」「明日の昼、アリョーナがとんでもない提案を持ってくるわよ」など、翌日のログインが待ち遠しくなる引きを設ける。
* **学習者への敬意と情熱の還元**:
  * 毎日の練習を継続するユウスケの努力が、物語世界の中でターニャやアリョーナの心を動かし、音楽院全体に波紋を広げていく実感を与えること。

## 5. 実在の作曲家名言とオリジナル台詞の住み分けルール

* **実在の作曲家・演奏家（チャイコフスキー、ラフマニノフ、ネイガウス等）の言葉**:
  必ず事前に一次史料（手記、書簡、開校演説等）から出典が確認・分類された公式名言バンク **[`data/canonical_composer_quotes.json`](file:///c:/Antigravity/Projects/learnRussian/data/canonical_composer_quotes.json)** からのみ引用する。勝手な作話や未確認の言行録の帰属は厳禁とする。
* **魅力的なセリフ・熱い感情描写**:
  文脈に合わせた心揺さぶる言葉、緊迫した練習室での掛け合い、学習者を熱狂させるドラマティックなセリフは、架空の人物である**ターニャ先生**や**アリョーナ**に思い切り語らせる。これにより、史実の信頼性を100%守りながら、ストーリーの面白さと自由度を極限まで高めることができる。
